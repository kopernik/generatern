# Искра

Мобильная версия [генератора заголовков](https://github.com/kopernik/generate) на Expo SDK 58 и React Native. Введите тему статьи, выберите стиль и количество вариантов. Готовые заголовки можно скопировать по одному или сгенерировать заново.

## Запуск

```sh
npm ci
npx expo start
```

Откройте приложение в Expo Go на iOS или Android. Для веб-версии используйте `npm run web`.

## API

По умолчанию приложение использует [опубликованный API проекта generate](https://generate-theta-seven.vercel.app). Чтобы указать другой сервер, скопируйте `.env.example` в `.env.local` и задайте `EXPO_PUBLIC_API_URL` без пути `/api/generate-headlines`. При запуске Express на компьютере используйте адрес, доступный с тестового устройства. Для физического устройства это IP компьютера в локальной сети, для Android Emulator — `10.0.2.2`. Ключ Cloudflare хранится в окружении сервера generate.

Веб-версия обращается к API через серверный маршрут Expo Router, поскольку опубликованный API не поддерживает CORS. При публикации веб-версии нужен хостинг с поддержкой серверной сборки Expo.
